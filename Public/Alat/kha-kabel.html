Analisis desain sheath

  • Hitung terlebih dahulu untuk menghasilkan rekomendasi.
Formula CIGRE yang digunakan
mu0 = 4*pi*10^-7 H/m
rs = d/2
X = omega*mu0/(2*pi)*ln(S/rs) [ohm/m]
Single-point: Vs = X*I*L, Is approx 0
Mid-point: Vs approx = X*I*(L/2), Is approx 0
Solid bonding trefoil: eta = X / sqrt(Rs^2 + X^2), Is = eta*I
Cross-bonding 2 minor sections: Is approx = 0.5*eta*I
Cross-bonding 3 minor sections: residual voltage = X*I*abs(L1 + a^2*L2 + a*L3), a = exp(j*120 deg)
Ws = Is^2*Rs
Wc = I^2*R
Loss factor = Ws/Wc

Analisis thermal dan rekomendasi

  • Hitung terlebih dahulu untuk menghasilkan rekomendasi.
Formula IEC 60287 yang dipakai di tab ini
DeltaTheta = thetaMax - thetaAmbient - DeltaThetaExternal
Rac = resistance conductor at thetaMax [ohm/m]
Thermal denominator D = Rac*T1 + Rac*(1+lambda1)*T2 + Rac*(1+lambda1+lambda2)*(T3+T4)
Dielectric term = Wd*(0.5*T1 + T2 + T3 + T4)
I_cont = sqrt((DeltaTheta - Dielectric term) / D)
I_derated = I_cont * groupDerating * sqrt(loadFactor)
Temperature at operating current = thetaAmbient + DeltaThetaExternal + dielectric term + I^2*D
For quick buried estimate: T1 approx rhoIns/(2*pi)*ln(Dins/Dc), T4 approx rhoSoil/(2*pi)*ln(4*depth/De)
Untuk desain final, gunakan data kabel lengkap, thermal resistivity aktual hasil pengukuran, konfigurasi duct/backfill, nilai lambda dari perhitungan sheath aktual, serta derating crossing heat source bila ada.

Formula CIGRE TB 880 yang digunakan (IEC 60287)
=== CONDUCTOR AC RESISTANCE (IEC 60287-1-1 §2.1) === Rdc(θc) = R0 × [1 + α20 × (θc − 20)] [Ω/m] xs² = 8π·f·ks / (R'×10⁷) ys = xs⁴ / (192 + 0.8·xs⁴) [skin effect] xp² = 8π·f·kp / (R'×10⁷) yp = xp⁴/(192 + 0.8·xp⁴) × (dc/s)² × [0.312(dc/s)² + 1.18/(xp⁴/(192+0.8·xp⁴) + 0.27)] Rac = Rdc(θc) × (1 + ys + yp) [Ω/m] === CAPACITANCE & DIELECTRIC LOSS === C = 2πε₀ε / ln(Di/dc) [F/m] Wd = ω·C·U₀²·tan(δ) [W/m per phase] U₀ = U/√3 === SHEATH REACTANCE === X = ω·μ₀/(2π)·ln(2s/d) [Ω/m] (trefoil/flat equally spaced) === SHEATH RESISTANCE AT TEMPERATURE === Rs0 = ρ₂₀ / (π·d·ts) [Ω/m at 20°C] Rs(θs) = Rs0 × [1 + α₂₀·(θs − 20)] [Ω/m at θs] === SHEATH LOSS FACTOR (solid bonded, §2.3.1) === λ₁' = (X/Rs)² / (1 + (X/Rs)²) × (R/Rac) ... simplified: λ₁ = X²/(Rs² + X²) [for solid bonded, single-core trefoil/flat] (single-point or cross-bonded: λ₁ = 0) === THERMAL RESISTANCE T1 (§4.1.2.1) === T1 = sum of layers: ρT_layer/(2π) × ln(d_outer/d_inner) inner SC: ρT_sc1/(2π) × ln(dc + 2·tsc1)/dc insulation: ρT_ins/(2π) × ln(Di/dc_aft_sc1) outer SC: ρT_sc2/(2π) × ln(Di + 2·tsc2)/(Di) === THERMAL RESISTANCE T3 (§4.1.4.1) === T3 = ρT_oversheath/(2π) × ln(De/(De − 2·t3)) × 1.6 (for touching trefoil buried, §4.2.4.3.2) === THERMAL RESISTANCE T4 BURIED (§4.2.4.3.2) === Touching trefoil: T4 = 1.5·ρT_soil/π × [ln(2u) − 0.630] where u = 2L/De CIGRE TB 880 GP8 (exact): T4 using ln(u + √(u²−1)) − 0.630 × 1.5/π === PERMISSIBLE CURRENT (§1.4.1.1) === I = √[ (Δθ − Wd·(0.5·T1 + T2 + T3 + T4)) / (Rac·(T1 + (1+λ₁)·(T2 + T3 + T4))) ] Δθ = θc_max − θa === ITERATIVE PROCESS === 1. Init θs = θc_max − 10 °C 2. Calc Rs(θs), λ₁, I 3. Wc = Rac·I², Ws = λ₁·Wc 4. θj = θa + n·(Wc+Ws+Wd)·T4 θs = θj + n·(Wc+Ws+Wd)·T3 5. Repeat until |ΔI| < εI and |Δθs| < εI/10
